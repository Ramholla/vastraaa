# Vastraa - Premium Streetwear E-commerce (Demo)

Two versions in this repo:
- Vastraa_Complete_Mock: Demo-ready, includes mock images and sample product data.
- Vastraa_Minimal_Placeholder: Clean starter with placeholders for you to add products.

## Setup (both)
1. `npm install`
2. `npm run dev`
3. Open http://localhost:5173 (Vite default)

Tech: React + Vite + Tailwind (Tailwind directives included in globals.css).
Accent color: Neon Green (#00FF88)
